============================================================
ПАРОЛИ МЕХАНИКАМ (мастерам) — куда нажать
============================================================
Актуально на 28.09.2026 (коммит 33220d2)

ВАРИАНТ 1. Через «Работники (техслужба)» (основной)
------------------------------------------------------------
1. Меню: «Работники (техслужба)» (старое название: Техническая Служба)
2. Найти мастера → кнопка Edit
3. А) Логина ещё нет:
      блок «Create system login for this worker»
      Username + Password → Create Login
   Б) Логин уже есть:
      блок «Reset password» (оранжевый)
      • New password — ввести свой
        ИЛИ
      • Generate — случайный (10 символов, показывается 1 раз)
      • галочка «Require change at next login»
      • Reset password

ВАРИАНТ 2. Через «Пользователи»
------------------------------------------------------------
Пользователи → карточка мастера → поля New password / Confirm
или кнопка смены пароля в карточке.

ВАРИАНТ 3. Через «Monteurs / Access Permissions»
------------------------------------------------------------
Monteurs (доступ admin) → карточка → поле «New password»
(«Keep current» = не менять) → Сохранить.

ЗАМЕЧАНИЯ
------------------------------------------------------------
- Пароль после Generate виден только один раз во flash-сообщении.
- Сброс пишется в Audit Log (кто и когда).
- Доступ: admin, director.
- Служебная учётка «Technicus» — системная, не трогать.

ПРОСМОТР ПАРОЛЯ АДМИНОМ
------------------------------------------------------------
Пользователи → карточка → поле «Current Password (admin)»
(кнопка глаз показывает/скрывает).
Также на карточке работника и в Monteurs.
Хранится только для роли admin — другие не видят.
Если поле пустое: пароль был задан до этого обновления —
смените пароль, и он появится.
