ГЛАВНАЯ ПРИЧИНА «ТЕЛЕФОН МОЛЧИТ» (прод, PythonAnywhere):
  Web-процесс (uWSGI, Python 3.10, venv ~/.virtualenvs/crm) не мог импортировать
  pywebpush — цепочка падала по неделям: aiohttp (14.11) → attr (23.11) →
  idna (24.11) → typing.Self (26.11). Push НЕ отправлялись минимум с 8 ноября;
  in-app колокольчик работал, поэтому казалось, что «логика» исправна.
  Три корня:
  а) пакеты лежат в /usr/local/lib/python3.10/dist-packages (Debian), venv их не
     видит, а push.py добавлял в sys.path только user-site + purelib;
  б) user-site других версий python (3.13) подсовывал кросс-версионные пакеты
     новее текущего python (yarl/requests → typing.Self на 3.10);
  в) авто-установка pywebpush в app.py запускала pip через sys.executable —
     под uWSGI это /usr/local/bin/uwsgi, установка молча не выполнялась,
     а returncode pip никто не проверял («background install finished»).
