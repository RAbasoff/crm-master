5) INFRA: Автоматический SSH-деплой на PythonAnywhere
   Дата: 30.09.2026
   Коммиты: 3887ab2 (docs), деплой на PA подтверждён
   Описание:
     Настроен passwordless SSH с PA. Деплой теперь делается
     агентом без участия пользователя.
   Как настроено:
     - Ключ уже был: C:\Users\abaso\.ssh\id_ed25519 (ed25519)
       pub: ssh-ed25519 AAAA...Pl abasoff-pa-deploy
     - Раздела «SSH keys» в веб-морде PA НЕТ (ошибка в инструкции).
       Ключ добавляется в файл ~/.ssh/authorized_keys на сервере.
     - Через Bash-консоль PA выполнена команда:
       mkdir -p ~/.ssh && echo 'ssh-ed25519 ...' >> ~/.ssh/authorized_keys
       && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys
       → KEY_ADDED
     - Проверка: ssh rabasoff@ssh.pythonanywhere.com "echo OK" → SSH_OK
   Процедура деплоя (агент делает сам):
     1) git push origin master
     2) ssh rabasoff@ssh.pythonanywhere.com "cd ~/crm-master && git pull origin master"
     3) ssh ... "touch /var/www/rabasoff_pythonanywhere_com_wsgi.py"
        (перезагрузка веб-приложения)
   Статус: 30.09.2026 — задеплоено, пользователь подтвердил:
     «страница открывается, всё работает» (/electricity/outlets).
