   - Фильтрация по пользователю, отделу, периоду

   - Скомпилирован .mo файл для русского языка

4. Обновлены зависимости
   - openpyxl==3.1.5 (Excel)
   - python-docx==1.2.0 (Word)

5. Добавлены новые типы отчётов
   - Отчёт по ответственным: кто, когда, какие заявки передавал
   - Отчёт по станкам: заявки за период, всего, открытых, критичных
   - Экспорт новых отчётов в PDF, Excel, Word, CSV

6. Создан модуль полной статистики
   - Страница: /stats/full
   - Выбор периода: даты (от/до) или пресеты (7/30/90/365 дней)
   - Графики: заявки по приоритету, по статусу, топ станков, склад
   - Отчёт по станкам с фильтрацией по цеху
   - Экспорт в 5 форматах: PDF, Excel, Word, TXT, CSV
   - Печать

7. Обновлена карта цеха
   - Заменены эмодзи-иконки станков на SVG-иконки
   - Разные иконки для разных типов станков (CNC, пресс, сварка, конвейер, сверлильный, токарный, фрезерный, упаковочный, робот)
   - Градиентные фоны, улучшенные тени
   - Статус-индикация (цвет рамки)

8. Расширен функционал карты цеха
   - Клик по станку: показывает заявки, статистику, кнопки действий
   - Статистика: всего заявок, открытых, решённых, критичных
   - Список последних 10 заявок с приоритетом и статусом
   - Кнопки: Детали, Новая заявка, Новый TWO, Удалить заявку
   - API: /api/machine/{id}/faults
   - API: /faults/{id}/delete (для удаления заявок)

9. Цветовая индикация станков на карте
   - Зелёный: нет проблем
   - Жёлтый: есть открытые заявки
   - Красный: есть критичные заявки
   - Бейджи с количеством заявок на иконке
   - Легенда цветов на карте

10. Раздел настроек (расширен)
    - Страница: /settings
    - Вкладка "Users": управление ролями и доступом к отделам
    - Вкладка "Responsible": управление ответственными (телефон, внутренний номер, email, группа)
    - Вкладка "Machines": управление станками с фильтрацией по отделам
    - Вкладка "Sections": управление отделами цеха (цвет, позиция, размер)
    - Вкладка "Groups": управление группами и правами
    - Ссылка на редактор карты
    - API: /settings/user/{id}/access
    - API: /settings/section/{id}/update
