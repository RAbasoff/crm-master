  - machine_edit(): при замене фото старый файл удаляется с диска

ТЕСТ (Flask test client):
  - станок A (красный) и B (зелёный), оба photo.png
  - A.photo != B.photo, содержимое разное → OK
  - замена фото у A не трогает B → OK

5.1 ensure_schema() — честная сверка схемы (c8578a3)

  Было:
    - миграции пропускались по SCHEMA_VERSION
    - CREATE TABLE IF NOT EXISTS не добавлял колонки
    - except Exception: pass глотал ошибки
    - rebuild 3 таблиц на КАЖДОМ старте (строчный поиск NOT NULL)

  Стало:
    - ensure_schema() ВСЕГДА запускается, идемпотентна
    - модели SQLAlchemy = источник истины: недостающая колонка → ALTER ADD
    - rebuild через PRAGMA notnull (только когда реально нужно)
    - каждая ошибка → SCHEMA ERROR в лог
    - SCHEMA_VERSION штампует ТОЛЬКО run_data_migrations()

  ТЕСТ: легаси chat_message (chat_id/message) получил room_id/body/status_json
  + backfill. Повторный запуск: cols+0 rebuilds=0. Запрос /chat/ работает.
