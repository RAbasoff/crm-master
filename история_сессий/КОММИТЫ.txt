Сброс пароля мастера из админки.
- POST /workers/<id>/reset-password (admin/director)
- Ввод пароля ИЛИ авто-генерация (кнопка Generate)

- Audit log: кто сбросил

ГДЕ СБРОСИТЬ/НАЗНАЧИТЬ ПАРОЛЬ МЕХАНИКУ:
1. Работники → карточка мастера → Edit
2. Если логина ЕЩЁ НЕТ — блок «Create system login»:
   Username + Password → Create Login
3. Если логин УЖЕ ЕСТЬ — блок «Reset password»:
   - введите новый пароль ИЛИ оставьте пустым
   - кнопка Generate — случайный пароль (покажется 1 раз)
   - Reset password
4. Также можно: Пользователи → карточка → New password
5. Также можно: Monteurs (Access Permissions) → поле «New password»
   → сохранить.
