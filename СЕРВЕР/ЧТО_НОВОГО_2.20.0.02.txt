ЧТО НОВОГО в версии 2.20.0.02 (26.11.2026)

ОПОВЕЩЕНИЯ НА ТЕЛЕФОН (Push — звук / вибрация / блок-экран):
- Push-уведомления на телефон ВОССТАНОВЛЕНЫ: исправлена работа библиотек
  на сервере — уведомления не доходили до телефонов несколько недель
  (колокольчик в программе работал, телефон молчал)
- Заявитель получает полный цикл уведомлений на своём языке, с временем:
  ЗАЯВКА СОЗДАНА / ПРИНЯТА / НАЗНАЧЕН МЕХАНИК / НА ПАУЗЕ (с причиной) /
  РЕШЕНО / ЗАЯВКА ЗАКРЫТА
- Причина паузы в уведомлениях — текстом (напр. «Машину нельзя остановить»),
  а не служебным кодом
- Механики — уведомление о каждой новой заявке; директор — создание /
  пауза с причиной / решение / закрытие (как и раньше)
- АВТОПОДПИСКА на уведомления:
  * Android и компьютер — автоматически при входе в программу
  * iPhone — системный запрос по ПЕРВОМУ касанию экрана в любом месте
    (Apple запрещает автоматический запрос; кнопка «Включить уведомления»
    остаётся подстраховкой)
  * iPhone: программа должна быть запущена с иконки на «Домашнем экране»
- Настройка телефона сотрудника через «Войти под пользователем» теперь
  привязывает уведомления к СОТРУДНИКУ (раньше подписка цеплялась к админу,
  и сотрудник не получал push на своём телефоне)

ЗАЯВКИ (Storingen):
- Исправлена ошибка создания заявки обычным пользователем (красное сообщение
  «Fout bij aanmaken storingsmelding», заявка не создавалась)
- Ошибки формы создания заявки теперь пишутся в журнал (раньше терялись)
- Форма: починено поле «Фото» (сломанная разметка)
- Кривое значение поля «станок» больше не приводит к ошибке

ПРОЧЕЕ:
- Самопроверка отправки уведомлений (раз в сутки, контрольный push админам)
- Сбои отправки push пишутся в журнал системы
